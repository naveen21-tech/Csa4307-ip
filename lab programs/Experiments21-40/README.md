# Internet Programming Lab — Experiments 21–40

This folder contains the webpages for lab experiments 21 to 40.

## Run
1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Select an experiment card to open its webpage.

No build tools or server are required. The pages use plain HTML, CSS and JavaScript.

## Included
- Experiments 21–30: existing experiment webpages moved into this folder without changing their contents.
- Experiments 31–40: responsive, standalone HTML demos created from the supplied lab brief.
- `index.html`: experiment directory / launch page.

## Notes
These are front-end prototypes for lab demonstration. Demo form submissions are stored in browser `localStorage`. Real authentication, server-side database storage, payments, email, QR validation, maps and other external integrations require backend services/API credentials and are not represented as production-connected features.

Experiment numbering follows the supplied document. It labels the second item numbered 36 as **36B — BookHaven** to distinguish it from **36 — EduConnect**.
